# 프로젝트 목적

학생의 이름과 점수를 등록하고 관리할 수 있는 성적 관리 프로그램을 개발한다.  
프로그램은 등록된 학생 정보를 바탕으로 전체 학생 목록, 평균 점수, 최고 점수 학생을 제공한다.

# 필수 기능 목록

1. **학생 성적 등록**
   - 학생 이름을 입력받는다.
   - 학생 점수를 입력받는다.
   - 입력한 이름과 점수를 학생 정보로 저장한다.

2. **전체 학생 목록 조회**
   - 등록된 모든 학생의 이름과 점수를 조회한다.
   - 각 학생의 정보를 구분하여 표시한다.

3. **평균 점수 계산**
   - 등록된 전체 학생의 점수 평균을 계산한다.
   - 계산된 평균 점수를 표시한다.

4. **최고 점수 학생 조회**
   - 등록된 학생 중 가장 높은 점수를 가진 학생을 조회한다.
   - 해당 학생의 이름과 점수를 표시한다.

# 입력과 출력

## 입력

- 학생 이름
- 학생 점수
- 기능 선택 입력
  - 학생 성적 등록
  - 전체 학생 목록 조회
  - 평균 점수 계산
  - 최고 점수 학생 조회

## 출력

- 학생 등록 완료 결과
- 전체 학생 목록
- 전체 학생의 평균 점수
- 최고 점수 학생의 이름과 점수

## 예시

### 학생 등록

```text
학생 이름: 홍길동
점수: 85

학생 정보가 등록되었습니다.
```

### 전체 학생 목록

```text
전체 학생 목록
1. 홍길동 - 85점
2. 김철수 - 92점
```

### 평균 점수

```text
평균 점수: 88.5점
```

### 최고 점수 학생

```text
최고 점수 학생: 김철수 - 92점
```

# 예외 처리 요구사항

- 등록된 학생이 없는 상태에서 전체 목록을 조회하는 경우, 등록된 학생이 없음을 안내한다.
- 등록된 학생이 없는 상태에서 평균 점수를 계산하는 경우, 평균을 계산할 수 없음을 안내한다.
- 등록된 학생이 없는 상태에서 최고 점수 학생을 조회하는 경우, 최고 점수 학생이 없음을 안내한다.
- 점수 입력이 숫자가 아닌 경우의 처리 방식은 별도 정의가 필요하다.
- 점수의 허용 범위, 동일한 이름의 학생 등록 가능 여부, 최고 점수가 같은 학생이 여러 명일 때의 처리 방식은 별도 정의가 필요하다.
